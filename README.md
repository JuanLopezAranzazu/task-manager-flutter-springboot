# Task Manager con Flutter y Spring Boot

Aplicación de gestión de tareas desarrollada con **Flutter** en el frontend y **Spring Boot** en el backend.

## Descripción

Este proyecto permite crear, editar, eliminar y organizar tareas desde una interfaz moderna e intuitiva.\
La aplicación está diseñada como una solución full stack, con una API REST para la lógica de negocio y una interfaz móvil o multiplataforma para el usuario final.

## Tecnologías utilizadas

- **Flutter**: desarrollo de la interfaz de usuario.
- **Spring Boot**: creación de la API REST.
- **MySQL**: base de datos para almacenar tareas y su información.
- **Swagger**: documentación interactiva de la API.
- **Riverpod**: manejo de estados en Flutter.

## Funcionalidades

- Crear nuevas tareas.
- Listar tareas existentes.
- Editar tareas.
- Eliminar tareas.
- Administrar el estado de cada tarea.
- Persistencia de datos con MySQL.
- Documentación clara de endpoints con Swagger.
- Gestión eficiente del estado de la aplicación con Riverpod.

## Objetivo

El objetivo de esta aplicación es ofrecer una solución simple, escalable y bien estructurada para la gestión de tareas, separando responsabilidades entre frontend, backend y base de datos.
